# Trainscript

A Python training-records app for managing apprenticeship and workforce training data.
Built with Python and Conda. Designed to parse LMS exports and generate professional reports.

## Features

### Learners Summary Report
Parses a learner CSV export from your LMS and produces a monthly course-completion summary showing:
- Total students enrolled
- How many completed at least one course
- How many have no completions
- A ranked list of every course taken that month with completion count and % of class

## Usage

### From the terminal (CLI)

```bash
# Print summary to console
python run_learners_summary.py data/learners.csv

# Print + export HTML report
python run_learners_summary.py data/learners.csv --html
```

The HTML report is saved to `output/learners_summary.html`.

### Inside your app (Python)

```python
from reports.learners_summary import LearnersReport

report = LearnersReport("data/learners.csv")

# Print to console
report.print_summary()

# Export HTML report
report.export_html("output/learners_summary.html")

# Get raw data as a dictionary
data = report.summary_dict()
print(data["courses"])
```

## CSV Format

The report expects a learner CSV export from your LMS with this structure:

| Column | Description |
|---|---|
| `Name` | Student full name |
| `Email` | Student email address |
| `Last active` | Last activity timestamp (used for report month) |
| `Total number of courses` | Enrolled course count |
| `Passed courses` | Number of passed courses |
| `[Course Name] (uuid)` | One column per course, value is `Passed (X%)` or `In progress (X%)` |

> **Note:** Per-course completion dates are not included in this CSV format.
> The report month is derived from the most recent "Last active" date.
> To get exact completion dates per course, export a course-activity report from your LMS.
